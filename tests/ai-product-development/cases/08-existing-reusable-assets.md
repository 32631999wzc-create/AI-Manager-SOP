# Existing Reusable Assets

## 输入场景

为 MVP 补齐集成缺口。提供 VERIFIED_REUSABLE 的需求、设计、评估标准和相关代码，一个 PARTIAL 集成资产；另有资产为 PRESENT_UNVERIFIED、OUTDATED 或 CONFLICTING。只交付缺口及验证。

## 执行方式

从 Skill Kernel 开始，说明 Profile、节点状态/深度/范围、需要读取的 references 和下一步计划。场景资产是假定输入，真实执行须核实证据。本用例为人工行为回归，不授权部署或其他外部写入。
