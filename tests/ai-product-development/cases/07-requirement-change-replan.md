# Requirement Change / Replan

## 输入场景

MVP 开发中用户更改输出字段。交付目标、范围、主要约束不变，有仍有效的记录、产物和已完成任务。另做变体：用户把目标从 DEMO 改为 ENTERPRISE。

## 执行方式

从 Skill Kernel 开始，说明 Profile、节点状态/深度/范围、需要读取的 references 和下一步计划。场景资产是假定输入，真实执行须核实证据。本用例为人工行为回归，不授权部署或其他外部写入。
