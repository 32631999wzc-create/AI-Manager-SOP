# Regression

## Use

当 bad case 已确认并完成修复，需要防止原失败复现和相关能力退化时读取。

## Procedure

1. 将确认失败转为去重、版本化 case，记录来源 Evidence、触发版本、根因、预期行为、严重度、适用切片和所有者。
2. 选择最小可稳定复现输入；保留语义本质，移除无关噪声，敏感生产样本按治理规则脱敏或替代。
3. 修复前确认 case 能失败；修复后先运行定向 case，再按影响面运行必要的相邻能力与全量回归。
4. 检查为单一 case 过拟合、grader 漂移和测试污染；无法稳定判定的 case 进入人工 review，而非伪造确定性断言。
5. 关联修复版本、run evidence 和发布决策；需求或预期变化时创建新 case 版本，不静默改写历史预期。

## Completion

原失败被阻止、相邻关键能力未退化、证据关联修复版本，且回归集仍代表真实风险而非无限累积的重复样本。
