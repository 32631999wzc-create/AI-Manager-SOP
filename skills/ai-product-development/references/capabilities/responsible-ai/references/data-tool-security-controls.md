# Data, Tool and Security Controls

## Use

当系统处理敏感数据、检索外部内容、调用工具、执行动作或暴露新的攻击/权限边界时读取。

## Control Areas

- 数据：目的限制、最小收集、来源/许可、敏感字段、跨境/保留/删除、训练与评测再利用、访问与审计。
- 输入与检索：不可信内容、prompt injection、数据投毒、来源可信度、隔离和内容到指令的边界。
- 工具与动作：最小权限、allowlist、参数约束、身份传递、dry-run、确认、速率/金额限制、幂等与撤销。
- 输出与接口：敏感信息泄露、越权推断、不安全下游消费、结构校验和可信边界。
- 供应商与模型：数据处理条款、日志/训练使用、区域、版本变化、停机与替代路径。

## Procedure

1. 绘制数据和动作流：来源、处理、存储、外发、权限主体、工具调用和最终副作用。
2. 对每个信任边界建立 misuse/attack path，并优先消除能力或权限，而不是只加内容过滤。
3. 采用分层控制：产品范围、数据治理、身份权限、运行时验证、用户确认、监控审计和补救。
4. 为控制定义可观察测试与失败状态；对不可恢复动作设置执行前保护，对泄露/滥用定义 containment。

## Completion

敏感数据与外部动作均有授权和最小权限，主要攻击/误用路径有可测试控制，供应商边界和残余风险透明。
